# 🚀 My Professional Portfolio

Welcome to my portfolio website! Is project me maine apne saare web development projects, skills, aur experience ko ek jagah showcase kiya hai. Yeh ek full-stack application hai jahan frontend user experience ko handle karta hai aur backend contact form/data management ko manage karta hai.

---

## 🛠️ Tech Stack

**Frontend:**
*   HTML5 & CSS3 (Responsive Design)
*   JavaScript (ES6+)

**Backend:**
*   Node.js
*   Express.js

---

## ✨ Features

*   **Responsive UI:** Mobile, tablet aur desktop sabhi screens ke liye perfectly optimized.
*   **Dynamic Projects Section:** Mere saare best projects ki list aur unke live links.
*   **Working Contact Form:** Express backend ka use karke contact form validation aur message submission functionality.
*   **Clean Code Architecture:** Frontend aur backend ka proper separation taaki code maintainable rahe.
